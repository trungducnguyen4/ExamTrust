## Các thành phần đã triển khai

1. **Hạ tầng Playwright (`FE/playwright.config.ts` & `package.json`)**:
   - Cài đặt `@playwright/test` và Chromium browser engine + FFmpeg.
   - Cấu hình viewport chuẩn Desktop Shell `1440 x 900` (đảm bảo hiển thị đầy đủ Sidebar 240px và Header).
   - Tích hợp `webServer` tự động tái sử dụng máy chủ đang chạy (`reuseExistingServer`) trên port 3000.
   - Bổ sung lệnh chạy:
     - Root: `npm run test:e2e` $\rightarrow$ `npm run test:e2e --prefix FE`.
     - FE: `npm run test:e2e`, `npm run test:e2e:ui`, `npm run test:e2e:report`.
   - Cấu hình `.gitignore` chặn các file kết quả và báo cáo tạm (`playwright-report/`, `test-results/`, `FE/e2e/.auth/`).

2. **Fixtures & Bộ kịch bản E2E cốt lõi (`FE/e2e/`)**:
   - `fixtures/test-users.ts`: Chuẩn hóa thông tin tài khoản test Sinh viên, Giảng viên và Quản trị viên theo seed DB.
   - `auth.setup.ts`: Tự động hóa đăng nhập và lưu phiên (`storageState`).
   - `login-and-layout.spec.ts`:
     - **TC-LOGIN-01**: Xác minh form đăng nhập, 3 nút vai trò demo, và tự động điền tài khoản.
     - **TC-LAYOUT-02**: Kiểm tra layout shell 1440px không bị lỗi tràn viền (horizontal overflow).
   - `exam-taking.spec.ts`:
     - **TC-EXAM-01**: Luồng làm bài thi sinh viên, chuyển đổi giữa màn hình câu hỏi và màn hình kiểm tra bài làm ("Kiểm tra bài làm"), điều hướng câu hỏi, và tự động chụp Visual Proof screenshot vào `docs/screenshots/e2e-student-exam-taking.png`.
   - `double-submit-race.spec.ts`:
     - **CHAOS-01**: Thử nghiệm Chaos Monkey kích hoạt double-click nút Submit trong khoảng 10ms; kiểm tra cơ chế khóa nút `disabled` và chặn triệt để đột biến API trùng lặp.
     - **CHAOS-02**: Thử nghiệm double-click dồn dập vào đáp án câu hỏi; xác nhận giao diện giữ vững tính toàn vẹn và không phát sinh ngoại lệ unhandled.

3. **Nâng cấp Pre-Launch Attack Squad (`scripts/attack/`)**:
   - `audit-features.mjs`: Tích hợp kích hoạt tự động E2E Feature test `exam-taking.spec.ts` khi chạy với `RUN_E2E=1`.
   - `audit-chaos.mjs`: Tích hợp kịch bản kiểm thử Chaos Double-Submit Race Condition trên trình duyệt thật.

4. **Đóng gói AI Skill (`.agents/skills/playwright-runner/SKILL.md`)**:

   - Tích hợp quy trình xử lý lỗi kết hợp cùng `diagnostics` subagent khi test bị fail (Trace Viewer).
   - Đăng ký `playwright-runner` vào [`AGENTS.md`](file:///d:/KLTN2/ExamTrust/AGENTS.md).
