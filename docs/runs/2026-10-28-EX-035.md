# Handoff EX-035 — Deploy Free Cloud (Render + Aiven MySQL + Render Key Value + Vercel)

## 1. Mục tiêu
- Triển khai toàn bộ hệ thống ExamTrust lên môi trường Cloud hoàn toàn miễn phí 100% (0đ, không cần thẻ tín dụng).
- Kết nối Backend API (NestJS), Key Value (Redis/BullMQ) trên Render với cơ sở dữ liệu Aiven MySQL và Frontend trên Vercel.

## 2. Đã làm / đã xác minh
- **Render Blueprint Sync & Deploy**:
  - Đã cấu hình và kích hoạt `examtrust-kv` (Key Value / Redis) và `examtrust-api` (Docker web service) từ blueprint nhánh `feature/EX-035-render-free-deploy`.
  - Đã thiết lập `DATABASE_URL` kết nối tới Aiven MySQL với cờ SSL `?sslaccept=accept_invalid_certs`.
- **Database (Aiven MySQL)**:
  - Đồng bộ thành công Prisma Schema gồm toàn bộ 40 bảng: `npx prisma db push --skip-generate` hoàn tất trong 20.95s.
  - Đã seed dữ liệu ban đầu: 47 tài khoản người dùng (1 Admin, 10 Giảng viên, 36 Sinh viên), 12 khóa học và 507 câu hỏi ngân hàng.
- **Backend API (Render)**:
  - URL: `https://examtrust-api.onrender.com`
  - Endpoint kiểm tra sức khỏe: `GET https://examtrust-api.onrender.com/api/health` -> HTTP 200 `{"ok": true}`.
  - Endpoint tài liệu: `GET https://examtrust-api.onrender.com/docs` -> HTTP 200.
  - Endpoint tổng quan: `GET https://examtrust-api.onrender.com/api/system-overview` -> HTTP 200 (47 users, 12 courses, 247 questions).
  - Đăng nhập thực tế: `POST https://examtrust-api.onrender.com/api/auth/login` xác thực thành công cả tài khoản `admin@tdtutdtu.edu.vn` và `lecturer01@tdtutdtu.edu.vn`.
- **Frontend UI (Vercel)**:
  - URL: `https://exam-trust.vercel.app`
  - Đã kiểm tra HTTP GET trả về mã trạng thái 200 OK.
- **Local Environment Fix**:
  - Đã cấu hình `innodb_force_recovery=1` trong `c:\xampp\mysql\bin\my.ini` để ngăn MySQL crash do lỗi lệch sequence log khi chạy local.

## 3. Quyết định + lý do
- Dùng `?sslaccept=accept_invalid_certs` thay cho `?ssl-mode=REQUIRED` vì Prisma MySQL yêu cầu cú pháp `sslaccept`.
- Sử dụng Render Blueprint với Render Key Value để có Redis miễn phí chạy BullMQ hàng đợi ngầm mà không cần đăng ký thêm dịch vụ ngoài.
- Chạy cả NestJS API và `ai-worker.js` trong cùng một container thông qua `deploy/render/start.sh` để tối ưu chi phí và gói Free của Render.

## 4. File / đường dẫn chính xác
- Backend start script: `deploy/render/start.sh`
- Backend Dockerfile: `deploy/render/Dockerfile`
- Blueprint file: `render.yaml` trên nhánh `feature/EX-035-render-free-deploy`
- Handoff file: `docs/runs/2026-10-28-EX-035.md`

## 5. Lệnh kiểm tra / xác thực
- Kiểm tra Health: `Invoke-RestMethod -Uri "https://examtrust-api.onrender.com/api/health"`
- Kiểm tra Overview: `Invoke-RestMethod -Uri "https://examtrust-api.onrender.com/api/system-overview"`
- Kiểm tra Vercel: `Invoke-WebRequest -Uri "https://exam-trust.vercel.app" -UseBasicParsing`

## 6. Bước tiếp theo duy nhất
- Thiết lập UptimeRobot hoặc Cron-job.org ping định kỳ 10-14 phút/lần vào `https://examtrust-api.onrender.com/api/health` để chống cold-start (ngủ đông) trên gói Render Free.
