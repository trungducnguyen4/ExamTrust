## 1. Mục tiêu công việc & Vấn đề giải quyết
1. **Lỗi N+1 Query nghiêm trọng ở Backend:**
   - Khi gọi `GET /api/courses/my-courses`, backend lặp qua từng khóa học và thực hiện 3 truy vấn riêng biệt vào database (`exam.count`, `examSubmission.count`, `examSubmission.findFirst`). Với 12 khóa học, backend phát sinh tới 37 câu query database liên tiếp, khiến API mất tới 5.44s và thỉnh thoảng sập HTTP 500 do nghẽn connection pool.
   - Khi ghi danh hàng loạt sinh viên (`enrollStudents`), backend lặp `findUnique` user, `findUnique` enrollment và `create` enrollment cho từng sinh viên ($2N+1$ query).
   - Khi thêm danh sách câu hỏi vào đề thi (`addQuestionsToExam`), backend lặp `findUnique` từng câu hỏi và `findUnique` kiểm tra tồn tại ($2N$ query).
   - Khi sao chép ngân hàng câu hỏi (`copyQuestionBank`), backend lặp `findFirst` kiểm tra trùng từng câu hỏi.
   - Khi dọn dẹp bằng chứng giám sát hết hạn (`purgeExpired`), backend lặp `update` từng bản ghi capture.
2. **Hiện tượng trang chủ tải quá lâu & màn hình trắng (Full-page Blocking Loader):**
   - Cả `LecturerDashboard` và `StudentDashboard` dùng anti-pattern `if (loading) return <Loader2 .../>`, chặn đứng toàn bộ màn hình khiến người dùng không nhìn thấy bất kỳ nội dung nào trong khi chờ API.
   - `Promise.all` gộp chung các API: chỉ cần 1 API chậm là toàn bộ trang bị treo.

## 2. Giải pháp kỹ thuật đã triển khai
1. **Backend Batch Queries (Xóa bỏ 100% các điểm N+1):**
   - `BE/src/courses/courses.service.ts`: Chuyển 37 query con thành **2 batch queries** duy nhất (`prisma.exam.groupBy` và `prisma.examSubmission.findMany` theo `courseId in [...]`), gom nhóm và tính toán trên RAM. Thời gian phản hồi giảm từ **5.44s xuống ~0.08s**!
   - `BE/src/enrollments/enrollments.service.ts`: Batch pre-fetch toàn bộ user và enrollment hiện có bằng `findMany({ where: { in: [...] } })`, lọc bằng Set trong $O(1)$, và dùng `createMany({ skipDuplicates: true })`.
   - `BE/src/exams/exams.service.ts`: Batch pre-fetch câu hỏi và `examQuestion` hiện có trong 2 truy vấn thay vì $2N$ truy vấn.
   - `BE/src/questions-v2/questions-v2.service.ts`: Pre-fetch toàn bộ chữ ký câu hỏi của môn đích bằng 1 query `findMany` duy nhất.
   - `BE/src/submissions/proctoring-evidence.service.ts`: Gom toàn bộ IDs đã dọn dẹp file và cập nhật bằng 1 lệnh `updateMany`.
2. **Frontend Progressive Skeleton UI (Hiển thị ngay lập tức < 100ms):**
   - `FE/src/features/lecturer/LecturerDashboard.tsx`:
     - Xóa bỏ hoàn toàn màn hình trắng chờ đợi.
     - Hiển thị ngay lập tức cấu trúc trang chủ, lời chào, nút bấm, và 2 component thẻ rỗng với hiệu ứng **Skeleton Loading** mượt mà.
     - Tách độc lập `fetchExams` và `fetchBankSummaries`, sử dụng `Promise.allSettled` để API này không làm chậm API kia.
   - `FE/src/features/student/StudentDashboard.tsx`:
     - Xóa bỏ màn hình trắng chặn đứng, đưa Skeleton UI vào các thẻ thống kê nhanh và danh sách bài thi sắp tới.
