## 1. Mục tiêu & Yêu cầu của người dùng
Tại trang **Ngân hàng câu hỏi** (`QuestionBankManagement.tsx` dùng chung cho cả `/lecturer/question-bank` và `/admin/question-bank`):
1. **Click vào nội dung câu hỏi:** Khi hover vào phần "Nội dung" câu hỏi trong bảng, hiển thị hiệu ứng hover (cursor pointer, đổi màu `text-primary`, gạch chân `group-hover:underline`) và khi click vào sẽ mở modal xem chi tiết câu hỏi ("Xem trước câu hỏi").
2. **Hiển thị trực tiếp 2 nút Sửa và Xóa:** Trong cột "Thao tác", bỏ dropdown menu `...` ẩn giấu, hiển thị hẳn 2 nút bấm thao tác nhanh:
   - Nút **Sửa** (icon `Edit2` + chữ "Sửa"): chuyển hướng tới Question Editor.
   - Nút **Xóa** (icon `Trash2` + chữ "Xóa" màu đỏ destructive): kích hoạt modal xác nhận xóa câu hỏi.

## 2. Chi tiết triển khai (`FE/src/features/lecturer/QuestionBankManagement.tsx`)
1. **Hàm tiện ích `handleViewQuestion`:**
   - Trích xuất logic xem chi tiết câu hỏi thành `handleViewQuestion(question: Question)`.
   - Quản lý trạng thái `setPreviewQuestion`, gọi API `api.getQuestionById(question.id)`, và set `setDetailQuestion`.
2. **Cột Nội dung (Content Cell):**
   - Bọc nội dung và icon media (ảnh/âm thanh) bên trong button dạng accessible:
     ```tsx
     <button
       type="button"
       onClick={() => void handleViewQuestion(question)}
       className="group flex items-center gap-2 text-left w-full hover:text-primary transition-colors focus:outline-none"
       title="Bấm để xem chi tiết câu hỏi"
     >
       ...
       <span className="block truncate font-medium text-foreground group-hover:text-primary group-hover:underline transition-colors">
         {question.content}
       </span>
     </button>
     ```
3. **Cột Thao tác (Actions Cell):**
   - Loại bỏ `<DropdownMenu>` và `<MoreHorizontal />`.
   - Hiển thị trực tiếp 2 nút bấm:
     - Button **Sửa**: variant `ghost`, icon `Edit2`, dẫn đến `questionEditorPath`.
     - Button **Xóa**: variant `ghost`, text màu đỏ `text-destructive`, hover nền đỏ nhẹ `hover:bg-destructive/10`, kích hoạt `handleDelete(question.id)`.
   - Cập nhật header cột: `<TableHead className="w-36 text-center whitespace-nowrap">Thao tác</TableHead>`.
