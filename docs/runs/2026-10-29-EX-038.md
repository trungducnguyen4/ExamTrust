## 2. Root Cause Identified
- Dù Lighthouse static đạt 90+, runtime dashboard bị đơ 7-8s do:
  1. `LecturerDashboard.tsx` gọi `fetchAllQuestions()`: dùng `Promise.all` vét cạn toàn bộ database câu hỏi (`page=1&limit=100`, `page=2&limit=100`,...) chỉ để hiện 4 item widget.
  2. `courses.service.ts` hàm `getMyCoursesAsLecturer`: N+1 query nặng (1 khóa học chạy 5 sub-queries riêng lẻ, 5 khóa học = 26 queries đồng thời sang Aiven MySQL).
  3. Render Free Tier bị CPU throttling (0.1 vCPU), nghẽn hàng đợi request tới ~7.8s.

## 3. Changes Applied
- `FE/src/features/lecturer/LecturerDashboard.tsx`:
  - Thay `fetchAllQuestions()` bằng `fetchRecentQuestions()` với `limit: 20`.
  - Giới hạn `api.getExams({ limit: 6 })`.
  - Lấy tổng câu hỏi từ `course._count.questions` thay vì tự đếm thô trên frontend.
  - Loại bỏ state biến `questionCount` thừa.
- `BE/src/courses/courses.service.ts`:
  - Thêm `_count: { select: { enrollments: true, exams: true, questions: true } }` vào `findMany` gốc.
  - Tránh sub-queries tính lượt nộp nếu khóa học không có đề thi nào.
