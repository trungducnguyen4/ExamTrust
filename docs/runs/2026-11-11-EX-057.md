## Các thành phần đã triển khai

1. **Skill Diagnostics (`.agents/skills/diagnostics/SKILL.md`)**:
   - Định nghĩa quy trình 5 bước: Reproduce ➔ Hypothesize ➔ Instrument ➔ Validate ➔ Synthesize.
   - **Ràng buộc Read-Only:** Subagent chẩn đoán tuyệt đối không sửa code, không commit hay push; chỉ điều tra và chứng minh nguyên nhân gốc rễ trước khi Main Agent bắt tay vào sửa.
   - **Định dạng chuẩn hóa `DIAGNOSTIC REPORT` (9 phần):**
     1. Problem Summary
     2. Reproduction Steps & Minimal Case
     3. Evidence Collected
     4. Root Cause Analysis
     5. Alternative Hypotheses Evaluated & Disproved
     6. Affected Files & Line Numbers
     7. Recommended Minimal-Touch Fix
     8. Regression Prevention Tests
     9. Confidence Level

2. **Claude Code Subagent Adapter (`.claude/agents/diagnostics.md`)**:
   - Sử dụng cơ chế phân nhánh ngữ cảnh `context: fork` với agent role `Explore`.
   - Đảm bảo toàn bộ quá trình grep, đọc code và chạy thử không làm phình context chính của Claude.

3. **Cập nhật `AGENTS.md` & `.clinerules`**:
   - Đăng ký `diagnostics` vào danh mục kỹ năng chính thức.
   - Bổ sung sơ đồ kiến trúc luồng ủy thác chẩn đoán:
     `Main Agent ➔ Isolated Subagent (Read-Only) ➔ DIAGNOSTIC REPORT ➔ Main Agent (Fix & Verify)`.
   - Hướng dẫn cấu hình tương thích cho cả Antigravity, DeepSeek Harness, Claude Code, Codex và Cline.
